## Function

- Description: Performs an element-wise addition operation on the input tensor list and input scalar list.

- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  scalars = [{scalars_0}, {scalars_1}, ... {scalars_{n-1}}]\\
  y = [{y_0}, {y_1}, ... {y_{n-1}}]\\
  $$

  $$
  y_i=x_i+scalars_i (i=0,1,...n-1)
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call the "aclnnForeachAddScalarListGetWorkspaceSize" API first to obtain the workspace size required for the computation and the executor that contains the operator computation process. Then call the "aclnnForeachAddScalarList" API to perform the computation.

```Cpp
aclnnStatus aclnnForeachAddScalarListGetWorkspaceSize(
  const aclTensorList *x,
  const aclScalarList *scalars,
  const aclTensorList *out,
  uint64_t            *workspaceSize,
  aclOpExecutor      **executor)
```

```Cpp
aclnnStatus aclnnForeachAddScalarList(
```
