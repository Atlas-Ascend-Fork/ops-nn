## Function

- Description: Updates the first input tensor list in place. Performs element-wise multiplication on two input tensor lists and writes the result back to the first list in place.

- Formula:

  $$
  x1 = [{x1_0}, {x1_1}, ... {x1_{n-1}}], x2 = [{x2_0}, {x2_1}, ... {x2_{n-1}}]\\
  $$

  $$
  x1_i = {x1_i}*{x2_i} (i=0,1,...n-1)
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnForeachMulListInplaceGetWorkspaceSize" API to obtain the workspace size required for computation and the executor that contains the computation process of the operator, and then call the "aclnnForeachMulListInplace" API to perform the computation.
