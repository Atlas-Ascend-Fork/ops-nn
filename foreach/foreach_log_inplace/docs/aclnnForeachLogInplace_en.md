## Function

- Description: Updates the input tensor list in place by computing the natural logarithm element-wise for each tensor in the list.

- Formula:

  $$
  x = [{x_0}, {x_1}, ... {x_{n-1}}]\\
  $$

  $$
  x_i = \ln(x_i) (i=0,1,...n-1)
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnForeachLogInplaceGetWorkspaceSize" to obtain the workspace size required for computation and the executor that contains the computation process, and then call "aclnnForeachLogInplace" to perform the computation.

```Cpp
aclnnStatus aclnnForeachLogInplaceGetWorkspaceSize(
  aclTensorList       *xRef,
  uint64_t            *workspaceSize,
  aclOpExecutor      **executor)
```

```Cpp
aclnnStatus aclnnForeachLogInplace(
  void          *workspace,
  uint64_t       workspaceSize,
  aclOpExecutor *executor,
  aclrtStream    stream)
```

  // Calculate the strides of the contiguous tensor.
  std::vector<int64_t> strides(shape.size(), 1);

  // Call the aclCreateTensor API to create an aclTensor.
  *tensor = aclCreateTensor(shape.data(), shape.size(), dataType, strides.data(), 0, aclFormat::ACL_FORMAT_ND,
                            shape.data(), shape.size(), *deviceAddr);
  return 0;
}
