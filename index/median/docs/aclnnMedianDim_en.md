## Function

  Computes the median and its index along a specified dimension of a tensor (if the number of elements along the specified dimension is size, the median corresponds to the sorted index `(size - 1) // 2`).

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnMedianDimGetWorkspaceSize" API to obtain the workspace size required for computation and the executor that contains the operator computation process, and then call the "aclnnMedianDim" API to execute the computation.

```Cpp
aclnnStatus aclnnMedianDimGetWorkspaceSize(
  const aclTensor *self,
  int64_t          dim,
  bool             keepDim,
  aclTensor       *valuesOut,
  aclTensor       *indicesOut,
  uint64_t        *workspaceSize,
  aclOpExecutor  **executor)
```

```Cpp
aclnnStatus aclnnMedianDim(
  void          *workspace,
  uint64_t       workspaceSize,
  aclOpExecutor *executor,
  aclrtStream    stream)
```

## Constraints

- Deterministic computation:
  - aclnnMedianDim defaults to a deterministic implementation.

- If the data type of self is not FLOAT, FLOAT16, or BFLOAT16, an excessively large tensor size may cause the operator execution to time out (an aicpu error is reported, with reason=[aicpu timeout]). The maximum size limits for different data types (strongly related to the remaining memory of the device) are as follows:
   - INT64: 150000000
   - UINT8, INT8, INT16, and INT32 types: 725000000
- When self is of the BFLOAT16 data type, the dimension where dim is located being 1 is not supported, and scalars are not supported.

  return 0;
}
