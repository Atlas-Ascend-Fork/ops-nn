## Function

- Description: A variant of the activation function. aclnnHardsigmoid writes the computation result to the output tensor, and aclnnInplaceHardsigmoid writes the computation result back to the input tensor in place. The result has the same shape as the input tensor.
- Formula:

  $$
  Hardsigmoid(self)=clip(\alpha \times self + \beta, 0, 1)
  $$

  By default, $\alpha=\frac{1}{6}$, $\beta=\frac{1}{2}$, which is equivalent to the following piecewise formula:

  $$
  Hardsigmoid(self)=\begin{cases}
  &1, &if(self\gt3) \\
  &0, &if(self\le-3) \\
  &\frac{self}{6} + \frac{1}{2}, &otherwise
  \end{cases}
  $$

  When the input is INT32, the computation result is truncated and then converted to INT32 for output.

## Function Prototype

- aclnnHardsigmoid and aclnnInplaceHardsigmoid implement the same function. The differences are as follows. Select the appropriate operator based on your actual scenario.

  - aclnnHardsigmoid: Requires creating a new output tensor object to store the computation result.
  - aclnnInplaceHardsigmoid: Does not require creating a new output tensor object. The computation result is stored directly in the memory of the input tensor.

- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnHardsigmoidGetWorkspaceSize" or "aclnnInplaceHardsigmoidGetWorkspaceSize" API to obtain the workspace size required for the computation and the executor that contains the operator computation process, and then call the "aclnnHardsigmoid" or "aclnnInplaceHardsigmoid" API to execute the computation.
