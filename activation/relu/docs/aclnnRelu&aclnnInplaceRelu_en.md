## Function

- Description: Activation function that returns a tensor with the same shape as the input tensor. For values greater than or equal to 0, the original value is retained; for values less than 0, 0 is returned.
- Formula:

$$
relu(self) = \begin{cases} self, & self\gt 0 \\ 0, & self\le 0 \end{cases}
$$

## Function Prototype

- aclnnRelu and aclnnInplaceRelu implement the same function. The differences in usage are as follows. Select the appropriate operator based on your actual scenario.
  - aclnnRelu: Create a new output tensor object to store the computation result.
  - aclnnInplaceRelu: No need to create a new output tensor object. The computation result is stored directly in the memory of the input tensor.

- Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). You must first call the "aclnnReluGetWorkspaceSize" or "aclnnInplaceReluGetWorkspaceSize" API to obtain the input parameters and calculate the required workspace size based on the computation process, and then call the "aclnnRelu" or "aclnnInplaceRelu" API to perform the computation.

```Cpp
  const aclTensor* self,

```
