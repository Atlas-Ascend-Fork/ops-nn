## Function

Fast Gaussian Error Linear Unit activation function.
FastGelu is defined as follows:

$$
FastGelu(x_i) = \frac {x_i} {1 + e^{-1.702 x_i}}
$$

where $x_{i}$ is an element of the input.

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call the "aclnnFastGeluGetWorkspaceSize" API first to obtain the workspace size required for the computation and the executor that contains the computation process, and then call the "aclnnFastGelu" API to execute the computation.

```Cpp
aclnnStatus aclnnFastGeluGetWorkspaceSize(
  const aclTensor *self,
  aclTensor       *out,
  uint64_t        *workspaceSize,
  aclOpExecutor  **executor)
```

```Cpp
aclnnStatus aclnnFastGelu(
  void            *workspace,
  uint64_t         workspaceSize,
  aclOpExecutor   *executor,
  aclrtStream      stream)
```
