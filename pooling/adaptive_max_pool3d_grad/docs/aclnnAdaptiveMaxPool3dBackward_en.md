## Function

- Description:
  Backward propagation of the forward adaptive max pooling. Backfills the gradient to the coordinates of the maximum value in each adaptive window, with accumulation at identical coordinates.
- Forward formula:
  N (Batch) represents the batch size, C (Channels) represents the feature map channels, D (Depth) represents the feature map depth, H (Height) represents the feature map height, and W (Width) represents the feature map width.
  For the scenario where the input self has dimensions $[N,C,D,H,W]$ and the outputSize value is $[D_o,H_o,W_o]$, the output dimensions are $[N,C,D_o,H_o,W_o]$, the indices dimensions are $[N,C,D_o,H_o,W_o]$, and the calculation formula for each element $(l,m,n)$ in the corresponding tensor is as follows:

  $$
  D^{l}_{left} = \lfloor(l*D)/D_o\rfloor
  $$

  $$
  D^{l}_{right} = \lceil((l+1)*D)/D_o\rceil
  $$

  $$
  H^{m}_{left} = \lfloor(m*H)/H_o\rfloor
  $$

  $$
  H^{m}_{right} = \lceil((m+1)*H)/H_o\rceil
  $$

  $$
  W^{n}_{left} = \lfloor(n*W)/W_o\rfloor
  $$

  $$
  W^{n}_{right} = \lceil((n+1)*W)/W_o\rceil
  $$

  $$
  output(N,C,l,m,n)=\underset {i \in [D^{l}_{left}, D^{l}_{right}],j\in [H^m_{left},H^m_{right}], k \in [W^n_{left},W^n_{right}] }{max} input(N,C,i,j,k)
  $$

  $$
  indices(N,C,l,m,n)=\underset {i \in [D^{l}_{left}, D^{l}_{right}],j\in [H^m_{left},H^m_{right}], k \in [W^n_{left},W^n_{right}] }{argmax} input(N,C,i,j,k)
  $$

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). Call "aclnnAdaptiveMaxPool3dBackwardGetWorkspaceSize" first to obtain the workspace size required for the computation and the executor containing the operator computation process, and then call "aclnnAdaptiveMaxPool3dBackward" to execute the computation.

## Constraints

- deterministic computation:
  <!-- npu="A3,910b" id11 -->
  - <term>Atlas A3 products</term>, <term>Atlas A2 products</term>: aclnnAdaptiveMaxPool3dBackward defaults to a non-deterministic implementation. Deterministic computation can be enabled using aclrtCtxSetSysParamOpt.
  <!-- end id11 -->
  <!-- npu="950" id12 -->
  - <term>Ascend 950PR&950DT products</term>: aclnnAdaptiveMaxPool3dBackward defaults to a deterministic implementation.
  <!-- end id12 -->

- For A2 and A3, in non-integer division use cases, the shape must not exceed 2^24. In integer division use cases, no such limit applies.

  *tensor = aclCreateTensor(shape.data(), shape.size(), dataType, strides.data(), 0, aclFormat::ACL_FORMAT_ND,
                            shape.data(), shape.size(), *deviceAddr);
  return 0;
}
